# ClassThreads Android app

This project wraps the ClassThreads web app (app/src/main/assets/index.html) in an Android app.

## Get the APK (no Android Studio needed)
1. Create a free GitHub account and a new repository.
2. Upload ALL files from this folder (including the hidden `.github` folder) to the repository.
3. Open the repository > **Actions** tab > **Build APK** > **Run workflow**.
4. After ~3 minutes, open the finished run and download **ClassThreads-apk** (a zip containing `ClassThreads.apk`).
5. Send the APK to classmates. They must allow "Install unknown apps" the first time.

## Updating the app
Replace `app/src/main/assets/index.html` with the newest version and run the workflow again.
